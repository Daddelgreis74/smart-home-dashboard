# Smart Home Dashboard 🏠👻

Ein hochmodernes, ästhetisch ansprechendes Smart-Home-Wandpanel mit Multi-Theme-Support, FRITZ!Box-Call-Monitor und Tasmota-Geräteverwaltung. Optimiert für den Dauerbetrieb auf Tablets (z. B. Lenovo Tab) im Fully Kiosk Browser.

## ✨ Highlights

* **Multi-Theme-System:** 4 wählbare Premium-Designs (Neo-Aurora, Cyberpunk HUD, Cozy Nordic, Retrowave Laser).
* **Fritz!Box Call Monitor:** Live-Anrufer-Overlay (Toast) auf allen Tablets und historische Anrufliste.
* **Tasmota-Einbindung:** Automatischer Subnetz-Scanner und schnelle Steuerung lokaler Smart-Home-Schalter.
* **Klima-Widget:** Unterstützung für AM2301 Tasmota-Temperatursensoren.
* **Abfallkalender:** Dynamischer Import von `.ics`-Dateien mit intelligenten Erinnerungs-Pills im Header.
* **Live Radio:** Integrierter DLNA/UPnP Mediaserver-Import deiner FRITZ!Box-Radiosender.

## ⚙️ TrueNAS-Einrichtung

1. **Host-Datenpfad:** Wähle einen permanenten ZFS-Ordner aus (z. B. `/mnt/tank/apps/smart-home-dashboard/data`), damit all deine Einstellungen, Kalender-Uploads und Fritz!Box-Verbindungsdaten auch nach Updates sicher erhalten bleiben.
2. **Standard-Port:** Das Dashboard läuft standardmäßig auf Port `8443`.
3. **Erster Aufruf:** Nach dem Starten der App kannst du das Dashboard direkt über den klickbaren **"Web Portal"**-Button öffnen.
