Kamera-Monitor

Anleitung: Kamera einbinden

Unterstützte Formate: Dieser Monitor benötigt eine Web-Adresse (beginnend mit http:// oder https://), die einen MJPEG-Videostream oder JPEG-Schnappschüsse liefert.

So findest du die richtige URL:

  • IP-Überwachungskameras: Binde die Kamera über die Hersteller-App in dein Heim-WLAN (Fritz!Box) ein. Viele Kameras bieten einen direkten MJPEG/JPEG-Pfad (z.B. http://192.168.178.50/snapshot.jpg).
  • Smartphone als Testkamera: Lade eine kostenlose App wie IP Webcam (Android) oder Live-Reporter (iOS) herunter. Starte den Server in der App. Du erhältst sofort eine funktionierende MJPEG-URL (z.B. http://192.168.178.60:8080/video) zum direkten Testen!
  • ESP32-Cam: Perfekt für Bastler. Nutze die Standard-Webstream-URL (z.B. http://192.168.178.70/stream).
  • Action-Kameras (wie GoPros / Jadfezy): Diese senden meistens nur ihr eigenes WLAN-Signal (AP-Modus). Verbinde sie per USB-Kabel mit dem Server und wähle „PC-Kamera / Webcam“. Streame das Bild dann über eine Software wie mjpg-streamer ins Heimnetz.

Hinweis zu RTSP: Reine Sicherheitskameras streamen oft nur in RTSP. Da Webbrowser RTSP nicht nativ anzeigen können, muss dieser Stream auf deinem Server zuvor per Software (z.B. go2rtc oder ffmpeg) in einen MJPEG-Stream umgewandelt werden.
