Was macht Neo Deck besonders?

Die Highlights auf einen Blick

6 Premium-Designs (Multi-Theme)

Wähle deinen Lieblings-Look direkt in den Einstellungen! Unterstützt Neo-Aurora (Glas & Glow), Cyberpunk HUD (Orange/Bernstein), Cozy Nordic (Mattes Schiefer & Salbei), Retrowave Synth (80s Neon-Grid), Terminal Classic (Matrix-Grün) und OLED Stealth (Nachtmodus).

Tasmota Smart Scan

Scanne dein gesamtes Heimnetzwerk mit einem einzigen Klick! Das Dashboard findet automatisch Tasmota-Lichter, Steckdosen und Schalter im privaten Subnetz.

Klimasensor-Visualisierung

Wandelt Rohdaten deines Tasmota AM2301 Sensors in atemberaubende, kreisförmige Gauges für Temperatur, Luftfeuchtigkeit und errechneten Taupunkt um.

Integriertes Live-Radio

Unterstützt MP3, AAC und HLS-Audiostreams (.m3u8). Preset-Tasten direkt auf dem Deck sorgen für schnelles Umschalten inklusive Fully Kiosk Wakeup-Schutz.

SVG System-Performance

Überwache CPU-Auslastung, RAM-Verbrauch und Speicherplatz in Echtzeit mit flüssigen, kreisförmigen SVG-Anzeigen. Hardwarebeschleunigt für butterweiche 60 FPS selbst auf schwächeren Tablet-CPUs.

Intelligenter Abfallkalender

Lade die `.ics`-Datei deiner Gemeinde hoch. Intelligente Berechnungen filtern Uhrzeit-Versätze heraus und zeigen an, welche Tonne Heute oder Morgen fällig ist.

Fritz!Box & WAN-Bandbreite

Überwache die Latenzen sowie Echtzeit-Download- und Upload-Geschwindigkeiten (in Mbit/s) deiner Fritz!Box. Eingehende Anrufe werden als pulsierendes Vollbild-Overlay signalisiert.

Anwesenheitserkennung (Fritz!Box)

Erkennt automatisch via TR-064 SOAP-Protokoll, welche Familienmitglieder im WLAN angemeldet sind. Aktive Personen leuchten mit pulsierendem Glow-Ring, abwesende werden sanft ausgegraut.

Multi-Wetter-Provider

Wähle zwischen Open-Meteo (schlüssellos, sofort einsatzbereit) und WeatherAPI.com (hochpräzise, kostenloser API-Key). Automatischer Fallback bei Verbindungsfehlern auf Cache oder alternativen Provider.

Müll-Erinnerung im Header

Verpasse nie wieder eine Leerung! Sobald eine Müllabfuhr für Heute oder Morgen ansteht, leuchtet im Header eine dynamisch generierte, animierte Pill-Erinnerung, perfekt farblich abgestimmt auf dein aktives Dashboard-Theme.

Premium Kamera-Monitor

Überwache bis zu 4 Kameras in einem dynamischen, responsiven Gitter (1, 2 oder 2x2). Unterstützt Live-MJPEG-Streams und JPEG-Schnappschüsse mit anpassbaren Intervallen sowie ein edles Tap-to-Fullscreen Milchglas-Overlay.

Integration Live-Status

Ein Live-LED-Statuspunkt direkt im Einstellungsmenü zeigt dir auf einen Blick, ob die Verbindung zu Fritz!Box, Tasmota-Geräten und Backend-Services aktiv steht. Keine blinden Diagnosen mehr.

Volle Mehrsprachigkeit

Das gesamte Dashboard lässt sich mit einem Klick übersetzen! Unterstützt Deutsch, Englisch, Französisch, Spanisch, Italienisch, Niederländisch und Polnisch für alle Steuerungselemente und Beschriftungen.

Moderne & schlanke Architektur

Node.js & Express

Ein leichtgewichtiges, schnelles HTTP-Backend zur sicheren lokalen Dateiverwaltung und API-Bereitstellung ohne Cloud-Abhängigkeiten.

Socket.IO

Ermöglicht ultra-schnelle, bidirektionale Echtzeitkommunikation für Systemdaten und nahtlose Layout-Synchronisation zwischen Geräten.

Lokale Härtung

IPv4 Validierung, Multer ICS Upload-Limits, Dateifilter und Radio URL-Normalisierung schützen den Server im privaten Netz.

Pure Vanilla JS

Keine schweren Frameworks (wie React/Vue) auf dem Tablet! Schnelles natives JavaScript sorgt für maximale Performance und minimalen RAM-Verbrauch.

Sortable.js

Unterstützt Drag & Drop Widget-Reihenfolge mit Fully Kiosk-optimierter Halte-Verzögerung gegen Scroll-Konflikte.

HLS.js

Ermöglicht das Streamen von HTTP Live Streaming (HLS) Audiokanälen directly im Webview ohne zusätzliche Plugins.

Quick Start

In 2 Minuten startklar

Windows Anleitung (Vollautomatisch)

Dank unserer vollautomatischen Startrampe ist das Setup auf Windows ein Kinderspiel und erfordert keine manuellen Terminal-Befehle oder SSL-Zertifikate:

  • 1
    Node.js installieren: Lade die aktuelle LTS-Version von nodejs.org herunter und installiere sie.
  • 2
    Doppelklick auf Start-Datei: Mache einfach einen Doppelklick auf die Datei start-dashboard.bat im Projektordner.
  • 3
    Zurücklehnen & Genießen: Die Batch-Datei prüft Pfade, installiert fehlende Bibliotheken, startet den Server (mit automatischem HTTP-Fallback) und öffnet direkt das Dashboard in deinem Webbrowser!

Linux & Raspberry Pi

Perfekt geeignet für den dauerhaften Betrieb auf einem Einplatinencomputer (z.B. Raspberry Pi) an der Wand:

  • 1
    Pakete installieren (Debian/Ubuntu/RPi OS): Installiere Node.js, den npm-Paketmanager sowie OpenSSL und Git über das Terminal deines Linux-Systems.
  • 2
    HTTPS-Zertifikate erstellen: Erstelle im Projektordner ein Verzeichnis ssl/ und generiere das SSL-Schlüsselpaar mit einem Einzeiler im Terminal.
  • 3
    Dauerhafter Betrieb im Hintergrund (PM2): Damit der Node-Server nach Stromausfällen oder Neustarts automatisch im Hintergrund hochfährt, installiere den Prozess-Manager pm2 und registriere die App.
bash - Linux & RPi Setup
user@pi:~ $ sudo apt update && sudo apt install -y nodejs npm openssl git
user@pi:~ $ cd smart-home-dashboard && mkdir -p ssl
user@pi:~ $ openssl req -nodes -new -x509 -keyout ssl/key.pem -out ssl/cert.pem -days 365 -subj "/CN=localhost"
user@pi:~ $ npm install
Pakete erfolgreich installiert...
user@pi:~ $ sudo npm install -g pm2
user@pi:~ $ pm2 start server.js --name "neo-deck"
user@pi:~ $ pm2 save && pm2 startup
[PM2] Autostart-Script erfolgreich registriert!

TrueNAS SCALE App-Installation

Bequemer Docker-Betrieb als Custom App direkt auf deinem TrueNAS SCALE NAS:

  • 1
    Custom App erstellen: Gehe auf deinem TrueNAS SCALE Web-Interface zu Apps → Discover Apps → Custom App.
  • 2
    Container-Image einrichten: Setze den App-Namen auf neo-deck und gib als Container-Image daddelgreis74/smart-home-dashboard:latest an.
  • 3
    Port & Netzwerk: Richte das Port-Mapping ein (z. B. Host-Port 8443 auf Container-Port 8443). Speichere die App, um das Dashboard automatisch zu deployen!
TrueNAS SCALE - Docker Compose Alternative
# Wenn du Docker Compose auf SCALE bevorzugst:
services:
neo-deck:
image: daddelgreis74/smart-home-dashboard:latest
container_name: neo-deck
ports:
- "8443:8443"
restart: unless-stopped
# Deployment per SSH: docker compose up -d

TrueNAS SCALE App Store (Ein-Klick-Installation)

Installiere Neo Deck mit nur einem einzigen Klick direkt aus dem Community-Katalog oder TrueNAS App Store:

  • 1
    Katalog öffnen: Navigiere zu Apps → Discover Apps im SCALE-Dashboard.
  • 2
    Nach "smart-home-dashboard" suchen: Gib smart-home-dashboard in die Suchleiste ein. (Stelle sicher, dass der TrueCharts- oder Community-Katalog aktiviert ist).
  • 3
    Installieren & Fertig: Klicke auf Install, belasse die Standardeinstellungen und klicke auf Save. TrueNAS lädt und konfiguriert das Dashboard vollautomatisch!

Automatisches SCALE-Routing

Das App-Template richtet das Web-Portal sowie die Netzwerkbrücke eigenständig ein. Nach der Installation ist das Dashboard direkt unter der IP deines NAS erreichbar.
